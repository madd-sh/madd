# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct.

The full text is published at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, assume good faith, critique ideas rather than people, and keep this a space where someone new to MADD feels safe asking a basic question.

## Reporting

If you experience or witness unacceptable behavior, report it privately at **conduct@madd.sh**. Reports are handled confidentially.

The maintainers may remove comments, commits, issues, discussions, and contributors that violate this code.
